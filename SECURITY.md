# Security reporting

Do not put credentials, setup codes, auth files, private logs or exploitable details
in public issues. A private reporting channel and named maintainer must be configured
before public release; no reporting inbox or response SLA is currently advertised.

Supported production releases have not yet been designated. Unsigned previews are
for review and acceptance testing. An unsigned status is not a signature-validation
result; validate the exact candidate and its provenance before release.
